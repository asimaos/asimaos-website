# Security

The website is static: no accounts, no forms and no third-party scripts, served with a strict
Content-Security-Policy. It also publishes the signed feed Asima Hub reads. A problem with either?
Please report it privately, never in a public issue: on
[github.com/asimaos/asimaos-website](https://github.com/asimaos/asimaos-website), open the
**Security** tab and choose **Report a vulnerability**.

The rest of the policy is Asima OS's: [SECURITY.md](https://github.com/asimaos/asimaos/blob/main/SECURITY.md).
